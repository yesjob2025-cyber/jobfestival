# 이력서 사진 — 실사 정장 템플릿

`suits.json` 에 등록한 정장 사진이 이력서 사진 화면에 **📷 실사 정장 사진** 으로 나타납니다.
목록이 비어 있으면(`[]`) 그 칸은 숨겨지고 그림 정장만 씁니다.

## 그림 규격

- **배경이 투명한 PNG** (사람 · 머리 없이 정장만, 목 부분은 비워 둠)
- 정면, 어깨가 수평, 가로 1200px 정도 (세로는 자유 — 가슴 아래까지 넉넉히)
- 무료 · 상업 이용 가능한 이미지만 쓰세요 (사진 앱의 "정장 합성" 소스, 직접 찍은 정장 사진 등)

## 등록 방법

PNG 를 이 폴더에 넣고 `suits.json` 에 한 줄씩 추가합니다.

```json
[
  { "id": "navy-tie", "name": "네이비 정장 + 넥타이", "file": "navy-tie.png", "neck": [600, 40], "shoulder": 1100 },
  { "id": "black-w", "name": "여성 블랙 정장", "file": "black-w.png", "neck": [600, 30], "shoulder": 1040 }
]
```

- `neck` — 그림 속 **목 가운데**(셔츠 깃 두 끝이 만나는 곳의 위쪽 중앙) 픽셀 좌표 `[x, y]`
- `shoulder` — **양 어깨 끝 사이 폭**(픽셀)

화면에서는 이 두 값으로 얼굴 크기에 맞춰 붙이고, "옷 위로 · 아래로 · 크게" 버튼으로 미세 조정할 수 있습니다.
