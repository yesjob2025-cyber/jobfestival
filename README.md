## 화면 구성

| 경로 | 설명 |
|------|------|
| `/` | 메인 — **포스터(클릭 시 참여기업 목록으로 이동)**, 행사 개요, 프로그램 요약 |
| `/companies` | 참여기업 목록 — 기업분류 탭 + 검색 |
| `/companies/[id]` | 기업 상세 — 부스번호·분류·업종, 채용설명회/멘토링 연계, 이전·다음 기업 |
| `/program` | 행사 프로그램 — 채용설명회 시간표, 동문 멘토, 부대 이벤트 |

외부 서비스(DB·API) 없이 **정적 데이터로만 동작**합니다. 환경변수 설정이 필요 없습니다.

## 빠른 시작

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # 프로덕션 빌드
```

## 내용 수정 방법

### 1) 포스터 이미지 교체

`public/` 폴더에 **`poster.jpg`** (또는 `poster.png` / `poster.webp`) 파일을 넣으면
메인 화면 포스터가 실제 이미지로 자동 교체됩니다. 파일이 없으면 코드로 그린 포스터가 표시됩니다.

### 2) 행사 정보 · 참여기업 · 프로그램

모든 내용은 **`src/lib/expo.ts`** 한 파일에서 관리합니다.

| 상수 | 내용 |
|------|------|
| `EXPO` | 행사명, 일시, 장소, 주최, 후원 |
| `COMPANIES` | 참여기업 (부스번호 · 기업명 · 기업분류 · 업종) |
| `SESSIONS` | 채용설명회 시간표 |
| `MENTORS` | 현직자 동문선배 멘토 |
| `EVENTS` | 부대 이벤트 |

**기업 상세 내용을 추가하려면** 해당 기업 항목에 아래 필드를 채우면 됩니다. (비워두면 화면에서 자동으로 숨겨집니다)

```ts
{
  id: "b01",
  boothNo: "01",
  name: "부산교통공사",
  category: "공기업",
  industry: "도시철도 운송업",
  intro: "여기에 기업 소개를 작성합니다.",   // 선택
  homepage: "https://...",                    // 선택
  hiring: ["운영직", "기술직"],                // 선택
}
```

채용설명회·동문 멘토는 **기업명이 일치하면 상세 페이지에 자동으로 연결**됩니다.

### 3) 배포

`main` 브랜치에 푸시하면 Vercel이 자동으로 빌드·배포합니다.
